# MuseClaw

[中文](README.md) | [English](README_EN.md)

> **企业常驻型多智能体数字员工工作站 (Enterprise Always-On Multi-Agent Workstation)**  
> 具备专属常驻沙箱、通讯录式多智能体协同、确定性安全哨兵风控、主动自动化例程、长期目标规划与跨端闭环协同的企业级 Agent 平台。

---

## 🎯 产品定位与核心价值

MuseClaw 旨在为每位企业员工构建**“专属的 AI 虚拟团队”**。区别于简单的即时问答对话框，MuseClaw 为每位员工提供专属隔离的常驻执行环境，以像通讯录般自然的交互方式统一调度不同专业角色的数字员工，无缝穿透企业内网系统与外部工作流。

### 核心代际差异

| 维度 | 传统对话式 Agent | 单任务执行沙箱 | **MuseClaw (本系统)** |
| :--- | :--- | :--- | :--- |
| **交互形态** | 单一聊天输入框，被动问答 | 单一任务临时执行卡片 | **虚拟团队通讯录（Roster UI）+ 双端同频（Web + 企业 IM）** |
| **组织架构** | 单一无差异 Prompt | 无组织角色概念 | **多智能体角色矩阵（独立 SOUL 设定、预设头像、专属技能与模型）** |
| **环境生命周期**| 无底层环境或无状态调用 | 按任务临时分配，运行即销毁 | **员工专属常驻沙箱（Always-On），持久化内网登录态与工作区** |
| **安全管控** | 依靠 Prompt 提示词防越权 | 基础正则命令过滤 | **确定性 Sentinel 哨兵内核（物理级拦截破坏性调用，双端审批）** |
| **主动性** | 零主动性（被动等待指令） | 仅能手工触发执行 | **主动自动化中枢（Cron 定时巡检、Webhook 入站唤醒、失败重试）** |
| **业务规划** | 无法管理长周期复杂目标 | 仅限瞬时单步指令 | **长周期目标规划引擎（阶段里程碑拆解、自主巡检节奏与备忘推进）** |
| **知识沉淀** | 文本上下文极易丢失或遗忘 | 无持久资产留存 | **受控记忆系统（长期受控固化 + 整理反思）+ 交付工件中心** |

## ✨ 核心特性矩阵

### 1. 👥 通讯录式多数字员工协同 (Roster Mode & Multi-Agent)
* **角色矩阵面板**：直观展示企业数字员工通讯录（数据分析助理、安全合规巡检员、运维工程师、代码审查员等）。
* **专属身份设定 (SOUL)**：每个数字员工拥有完全独立的 System Prompt、专属形象（动画/静态头像与 Emoji 选择器）、模型路由及挂载技能库。
* **主聊 / 旁聊分级架构 (Main Chat & Side Chats)**：为每位数字员工配备常驻置顶的「主聊」（Main Chat，常驻核心工作流，受保护免误删，持续沉淀会话记忆）与轻量隔离的「旁聊」（Side Chats，独立副任务并行处理，随时开启、搜索与销毁，彻底避免污染主任务上下文）。
* **AgentCapsule 实时状态交互**：支持会话顶部常驻悬浮与大卡片居中两种形态，实时呈现思考进度、工具执行微徽章与健康状态。

### 2. 🛡️ 确定性安全哨兵与合规审计 (Deterministic Sentinel & Audit)
* **物理拦截切面**：在命令执行与环境交互底层建立确定性风控拦截（物理级拦截高危 Shell 命令、越权删除、云凭据元数据泄露防护及 Loop Guard 熔断防死循环）。
* **动态挂起与求证 (Pending -> Approval -> Resume)**：高危动作自动挂起并向管理端派发审批，审批凭据绑定登录用户真实身份，防止越权伪造。
* **不可变审计流水**：全链路执行轨迹与审批决策实时持久化归档为结构化 JSONL 审计日志，提供直观的合规审计视图与 Grants 活跃授权管理。

### 3. 📱 企业 IM 双端闭环协同 (Enterprise IM Channels)
* **飞书 (Feishu / Lark)**：支持官方 SDK、WebSocket 长连接与 Webhook 双模式，高危审批以原生交互卡片推送，支持一键“批准/拒绝”按钮交互回写，提供富文本卡片排版与自动降级。
* **百度如流 (Infoflow)**：支持企业级 Webhook 签名验签、AES-256 数据加解密、多轮会话协同交互与文本审批指令闭环。
* **状态双向同频**：无论从 Web 界面还是移动端企业 IM 唤醒任务，执行上下文、审批流转与进度推送保持全局一致。

### 4. ⏱️ 主动自动化例程与事件驱动 (Proactive Routines & Webhooks)
* **Cron 周期调度**：内置标准 5 段式调度器与并发防重叠机制，支持中文自然语言周期语义识别与未来运行时间预测。
* **外部 Webhook 实时触发**：支持业务系统告警与工单事件入站唤醒，提供 Bearer 鉴权、429 并发速率限制与外部数据隔离保护。
* **健壮执行流水**：支持失败即刻重试（Retry）、完整工具调用链路追溯与主动告警推送。

### 5. 🎯 长周期目标规划中枢 (Long-Horizon Goals Engine)
* **多阶段里程碑拆解**：支持将复杂大型目标拆分为结构化里程碑与行内执行步骤，可视化展示进度百分比与推进状态。
* **自主巡检节奏 (Cadence Inspection)**：智能体依照既定频率主动巡检目标依赖，自动记录执行备忘并回写目标状态。

### 6. 🧠 受控记忆系统与技能生态 (Controlled Memory & Skills)
* **双轨受控记忆**：支持手工创建“受保护记忆”与多轮交互“自动沉淀记忆”，提供 Dry-run 整理预览、全文 Markdown 模态窗及容量配额看板。
* **技能规程库 (Skills Registry)**：预置开箱即用核心系统技能，支持 Zip 格式技能包一键导入、规程解析与沙箱动态挂载。

### 7. 💻 分布式 Runner Mesh 与多模型异构调度 (Runner Mesh & Providers)
* **跨平台伴侣守护进程 (`apps/runner`)**：支持 Linux (systemd)、macOS (launchd) 与 Windows 伴侣服务自启，具备双向心跳检测与网络自愈重连。
* **端侧 Agent 探针自动探测**：自动探测本地 Ollama、vLLM 及本地运行环境，支持主流云端大模型服务商（DeepSeek、OpenAI、Anthropic 等）无缝切换与统一路由。

### 8. 🎨 现代化 React 19 单页工作台 (Modern Web Workstation)
* **8 大核心功能视图**：对话工作台 (`ChatView`)、态势动态流 (`FeedView`)、目标看板 (`GoalsView`)、定时例程 (`RoutinesView`)、员工记忆 (`MemoryView`)、技能中心 (`SkillsView`)、安全审计 (`AuditView`)、成果工件 (`ArtifactsView`)。
* **全局非阻断微交互**：全面消除阻断式原生 `confirm()`，统一采用非阻断两步内联确认与波光呼吸动效，提供流畅的用户体验。

## 🧑‍💻 本地运行与快速上手

### 1. 环境准备
* **Node.js**: `>= 20.0.0`
* **pnpm**: `>= 9.0.0`

### 2. 环境变量配置
复制环境变量模版并补充必要凭据：

```bash
cp .env.example .env
```

主要配置项包括：
* 模型凭据：`DEEPSEEK_API_KEY` 等
* 飞书通道配置（可选）：`FEISHU_APP_ID`, `FEISHU_APP_SECRET`, `FEISHU_ENCRYPT_KEY`, `FEISHU_VERIFICATION_TOKEN`
* 如流通道配置（可选）：`INFOFLOW_TOKEN`, `INFOFLOW_AES_KEY`, `INFOFLOW_APP_ID`, `INFOFLOW_APP_SECRET`

### 3. 构建与启动

```bash
# 安装全量依赖
pnpm install

# 1. 构建前端生产产物 (gateway 托管 apps/web/dist)
pnpm --filter @museclaw/web build

# 2. 启动核心网关服务
pnpm dev                    # 访问工作台: http://localhost:8799

# (可选) 启动前端热重载开发服务器 (API 请求由 Vite 代理至 8799)
pnpm dev:web                # 访问开发界面: http://localhost:5173

# (可选) 启动本地分布式计算节点 / 伴侣守护进程
pnpm runner
```

### 4. 类型检查与代码校验

```bash
# 全局前端类型检查
pnpm exec tsc -p apps/web/tsconfig.json --noEmit
```

### 5. 运行核心功能回归自检

系统包含覆盖核心闭环、安全风控、多端通道及业务视图的自动化测试套件：

```bash
# 核心薄核状态机与哨兵拦截自检
npx tsx tests/verify-thin-core.ts

# 企业级安全加固与审计自检
npx tsx tests/verify-enterprise-hardening.ts

# 主聊 / 旁聊分级会话架构自检
npx tsx tests/verify-main-side-chat.ts

# 长期目标规划引擎自检
npx tsx tests/verify-long-horizon-goals.ts

# 主动例行任务与 Webhook 调度自检
npx tsx tests/verify-proactive.ts

# 受控记忆中枢自检
npx tsx tests/verify-memory-system.ts

# 飞书 / 如流企业通道自检
npx tsx tests/verify-feishu.ts
npx tsx tests/verify-infoflow.ts
```

## 🚀 初期开发成果交付总览 (Development Delivery)

MuseClaw 初期开发规划已全部按期保质交付：

- [x] **Milestone 1: 协议与薄核状态机 (Thin Core & Protocol)**
  - 确立全链路跨端事件标准契约（Task Plan, Approval Request, Stream Delta, Tool Trace）。
  - 实现极简 Agent Loop 状态机与底层统一环境抽象层。
- [x] **Milestone 2: 确定性安全门禁 (Deterministic Sentinel)**
  - 物理级拦截高危系统调用、敏感目录破坏与未授权网络请求。
  - 挂起与动态求证完整流程（Pending -> Approval -> Resume），审批结果不可篡改。
- [x] **Milestone 3: 企业 IM 通道与双端闭环 (Enterprise IM Channels)**
  - **飞书 (Feishu)**：长连接/Webhook 支持、事件加解密、原生审批卡片交互、双向会话同步。
  - **如流 (Infoflow)**：签名验证、AES-256 解密、多轮指令交互与文本审批闭环。
- [x] **Milestone 4: 主动例行自动化与事件驱动 (Proactive Automation)**
  - 5 段式标准 Cron 调度、中文周期语义识别与未来运行时间预测。
  - 外部 Webhook 实时唤醒、限流防护与执行流水失败快速重试机制。
- [x] **Milestone 5: 通讯录式多数字员工工作台 (Roster Mode & Modern Web)**
  - 基于 React 19 + TypeScript + Vite 重构完成现代化单页应用。
  - 交付 8 大核心业务视图（ChatView, FeedView, GoalsView, RoutinesView, MemoryView, SkillsView, AuditView, ArtifactsView）。
  - 落地数字员工花名册、SOUL 设定编辑器、形象/Emoji 抽屉与全量两步内联微交互。
- [x] **Milestone 6: 长期目标规划与自主受控记忆 (Long-Horizon Goals & Controlled Memory)**
  - 多阶段里程碑分解、行内快速子任务添加与自主巡检节奏（Cadence）。
  - 受保护记忆与自动沉淀记忆双轨流转、Dry-run 整理预览与配额监控看板。
- [x] **Milestone 7: 分布式 Runner Mesh 与多源模型中心 (Runner Mesh & Providers)**
  - 交付支持 Linux (systemd)、macOS (launchd)、Windows 的分布式伴侣常驻守护进程。
  - 自动探测本地端侧模型探针（Ollama、vLLM）与主流云端模型统一路由。
- [x] **Milestone 8: 技能生态、工件中心与合规审计 (Skills & Artifacts Ecosystem)**
  - 技能规程库构建，支持内置核心技能与 Zip 技能包动态上传与解析。
  - 交付物工件集中预览管理与基于 JSONL 的不可篡改全量合规审计中心。
